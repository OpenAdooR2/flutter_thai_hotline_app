# 🚀 Getting Started

## 1️⃣ Clone Project

```bash
git clone https://github.com/OpenAdooR2/flutter_thai_hotline_app.git
```

---

## 2️⃣ เข้าโฟลเดอร์โปรเจกต์

```bash
cd flutter_thai_hotline_app
```

---

## 3️⃣ ติดตั้ง Package

```bash
flutter pub get
```

---

## 4️⃣ Run Application

### Android / iOS

```bash
flutter run
```

### Chrome (Web)

```bash
flutter run -d chrome
```
